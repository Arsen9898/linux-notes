# linux-notes
# Шпаргалка по 20 базовым командам Linux

### Навигация и поиск путей
pwd — Показывает текущую папку.
ls — Выводит список файлов.
cd — Переходит в другую папку.

### Работа с файлами и папками
mkdir — Создает новую папку.
cat — Выводит содержимое файла.
less — Читает файл по страницам.
cp — Копирует файлы или папки.
mv — Перемещает или переименовывает.
rm — Удаляет файлы или папки.

### Поиск и фильтрация
grep — Ищет текст внутри файлов.
find — Ищет файлы в системе.

### Права доступа и администрирование
chmod — Меняет права доступа.
chown — Меняет владельца файла.
sudo — Запускает команду от админа.

### Информация о системе и процессах
ps — Показывает запущенные процессы.
top — Мониторит ресурсы в реальном времени.
df — Показывает свободное место на дисках.
du — Оценивает размер конкретных папок.

### Помощь и история
man — Открывает руководство к команде.
history — Показывает историю введенных команд.
