# 🐧 Права доступа в Linux (chmod)
При вводе `ls -l` слева отображается строка из 10 символов (например, `-rw-r--r--`), которая разбита на 4 зоны:
`[ тип ] [ владелец ] [ группа ] [ остальные ]`
`   -         rw-         r--          r--   `

## 👥 1. Кто есть кто (Категории)
*   **Тип (1-й символ):** `-` — обычный файл, `d` — директория (папка).
*   `u` (**User / Владелец**) — создатель файла.
*   `g` (**Group / Группа**) — команда/отдел, привязанный к файлу (например, `developers`).
*   `o` (**Others / Остальные**) — все остальные посторонние пользователи в системе.

---

## 🛠 2. Что означают буквы и цифры
Каждое право имеет свой буквенный символ и цифровой вес:

*   **`r` (Read / Чтение) = 4**
    *   Файл: открыть и прочитать.
    *   Папка: посмотреть список файлов (`ls`).
*   **`w` (Write / Запись) = 2**
    *   Файл: изменить содержимое или удалить.
    *   Папка: создавать и удалять файлы внутри неё.
*   **`x` (Execute / Выполнение) = 1**
    *   Файл: запустить как программу или скрипт.
    *   Папка: войти внутрь папки (`cd`).
*   **`-` (Нет прав) = 0**


## 🔢 3. Главные шаблоны в реальной работе
Права задаются тремя цифрами (`chmod XYZ`), где каждая цифра — это сумма весов (`4 + 2 + 1`) для Владельца, Группы и Остальных.

*   **`644` (`-rw-r--r--`) — Обычный документ**
    *   Владелец: читает и изменяет (`4+2=6`).
    *   Группа и Остальные: только читают (`4`).
*   **`755` (`-rwxr-xr-x`) — Публичный скрипт / папка**
    *   Владелец: делает всё (`4+2+1=7`).
    *   Группа и Остальные: могут только читать и запускать/входить (`4+1=5`).
*   **`600` (`-rw-------`) — Секретные ключи (SSH, пароли)**
    *   Владелец: читает и изменяет (`4+2=6`).
    *   Группа и Остальные: полный запрет, ничего не видят (`0`).
*   **`777` (`-rwxrwxrwx`) — Полный хаос (НЕБЕЗОПАСНО)**
    *   Абсолютно все могут читать, удалять и менять файл. В работе избегать.


## 💡 Бонус: Сравнение файлов (`diff`)
Команда показывает различия между двумя файлами: `diff старый_файл новый_файл`
*   `<` (влево) — строка из старого файла.
*   `>` (вправо) — строка из нового файла.


# Коротко про команды: Bandit 18-20
### 1. Выполнение команды через SSH без входа в систему
Если при входе на сервер тебя сразу выкидывает, можно выполнить команду удалённо, добавив её в кавычках в самый конец:
ssh bandit18@bandit.labs.overthewire.org -p 2220 'cat readme'

### 2. Запуск команды в фоновом режиме (&)
Знак & на конце отправляет команду работать на заднем плане, освобождая терминал для других действий:
echo "пароль" | nc -l -p 14888 &

### 3. Сетевой слушатель через Netcat (nc)
Открывает указанный порт на компьютере и ждёт входящих подключений:
* -l — слушать (listen)
* -p — номер порта (выбирай любой от 1024 до 65535)
```bash
nc -l -p 54321

# Команды chmod и работа с правами в Linux
* `touch testfile.txt` — Создаёт пустой файл для тестов.
* `chmod 600 testfile.txt` — Приватный режим (rw-------). Читать и менять файл могу только я ( владедец ).
* `chmod 755 testfile.txt` — Режим программы (rwxr-xr-x). Я могу всё, остальные — только читать и запускать.
* `chmod u+x testfile.txt` — Добавляет лично мне (u) право на запуск (+x) этого файла.
