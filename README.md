# Шпаргалка по 20 базовым командам Linux

### Навигация и поиск путей
pwd — Показывает текущую папку.
ls — Выводит список файлов.
cd — Переходит в другую папку.

### Работа с файлами и папками
mkdir — Создает новую папку.
cat — Выводит содержимое файла.
less — Читает файл по страницам.
cp — Копирует файлы или папки.
mv — Перемещает или переименовывает.
rm — Удаляет файлы или папки.

### Поиск и фильтрация
grep — Ищет текст внутри файлов.
find — Ищет файлы в системе.

### Права доступа и администрирование
chmod — Меняет права доступа.
chown — Меняет владельца файла.
sudo — Запускает команду от админа.

### Информация о системе и процессах
ps — Показывает запущенные процессы.
top — Мониторит ресурсы в реальном времени.
df — Показывает свободное место на дисках.
du — Оценивает размер конкретных папок.

### Помощь и история
man — Открывает руководство к команде.
history — Показывает историю введенных команд.

# Полный гид по правам доступа в Linux (permissions.md)

Когда мы вводим команду ls -l, слева от каждого файла мы видим строку из 10 символов, например: -rw-r--r--. 

Эта строка разбита на 4 логические зоны:
[ тип ][ владелец ][ группа ][ остальные ]
  -        rw-       r--        r--

## 1. Кто есть кто (4 зоны)

1. Тип элемента (1-й символ):
   - — это обычный файл
   d — это директория (папка)

2. Владелец / User (2, 3, 4 символы):
   Что с файлом может делать тот человек, кто его создал (владелец).

3. Группа / Group (5, 6, 7 символы):
Что с файлом могут делать люди из твоего отдела/команды. 
Пример:* Файлом владеешь ты, но группа у него developers. Значит, твои коллеги-программисты смогут его открыть, а бухгалтеры — нет.

4. Все остальные / Others (8, 9, 10 символы):
Что может делать любой другой посторонний пользователь в системе.

2. Что означают буквы (r, w, x)

r (Read) — право на чтение. Позволяет открыть файл или посмотреть список файлов в папке.
w (Write) — право на запись. Позволяет изменять/удалять файл или создавать файлы внутри папки.
x (Execute) — право на выполнение. Позволяет запускать файлы как программы/скрипты или заходить в папки (через cd).
- — право отсутствует.

3. Магия цифр (Запись прав через 4, 2, 1)

Вместо букв права часто задают тремя цифрами (например, chmod 755). Каждая цифра — это сумма прав для Владельца, Группы и Остальных.

Запомнить веса букв очень легко:
4 = r (Чтение)
2 = w (Запись)
1 = x (Выполнение)
0 = - (Нет прав)

4. Два главных примера в реальной работе

# Пример А: Права 755 (Для публичных папок и программ)
Используется, когда нужно, чтобы твоя программа работала у всех, но менять её код мог только ты.
Владелец (7): 4(r) + 2(w) + 1(x) = 7. Может всё (читать, менять, запускать).
Группа (5): 4(r) + 0(-) + 1(x) = 5. Могут только читать и запускать.
Остальные (5): 4(r) + 0(-) + 1(x) = 5. Могут только читать и запускать.
В буквах: -rwxr-xr-x

# Пример Б: Права 600 (Для секретных ключей и паролей)
Используется для максимальной приватности (как мы делали для sshkey.private). Никто, кроме владельца, не должен видеть файл.
* Владелец (6): 4(r) + 2(w) + 0(-) = 6. Ты можешь читать и редактировать свой ключ.
* Группа (0): 0 + 0 + 0 = 0. Полный запрет на любые действия.
* Остальные (0): 0 + 0 + 0 = 0. Полный запрет на любые действия.
* В буквах: -rw-------





# Сравнение файлов (diff)
Команда diff сравнивает два файла и показывает только различия между ними.

#Синтаксис:
diff passwords.old passwords.new

### Как читать значки:
< (Стрелка влево) — строка из старого (первого) файла.
> (Стрелка вправо) — строка из нового (второго) файла. **Это и есть нужный пароль.
